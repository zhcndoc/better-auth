仪表盘插件是您的 Better Auth 实例和 Better Auth 基础设施之间的核心连接。它为网页仪表盘提供实时数据，跟踪用户活动，并启用管理员 API。

## 安装

```ts
import { betterAuth } from "better-auth";
import { dash } from "@better-auth/infra";

export const auth = betterAuth({
  plugins: [
    dash(),
  ],
});
```

## 配置选项

| 选项                     | 类型       | 描述                                                                          |
| ---------------------- | -------- | --------------------------------------------------------------------------- |
| `apiUrl`               | `string` | Better Auth Infrastructure API URL。默认值：`https://dash.better-auth.com`       |
| `kvUrl`                | `string` | KV 存储 URL。默认值：`https://kv.better-auth.com`                                  |
| `apiKey`               | `string` | 用于身份验证的 API 密钥。如果环境变量中存在 `BETTER_AUTH_API_KEY`，则使用该变量的值。                    |
| `apiOptions`           | `object` | Dash API HTTP 客户端选项。接受以毫秒为单位的 `timeout?: number`。                           |
| `kvOptions`            | `object` | KV HTTP 客户端选项。接受 `timeout?: number` 和 `retry?: { attempts?: number; ... }`。 |
| `apiTimeout`           | `number` | `apiOptions.timeout` 的已弃用别名。                                                |
| `kvTimeout`            | `number` | `kvOptions.timeout` 的已弃用别名。                                                 |
| `activityTracking`     | `object` | 活动跟踪配置。                                                                     |
| `managedDirectorySync` | `object` | 托管目录同步控制平面选项。                                                               |

## 活动跟踪

跟踪用户在您的应用中的最后活跃时间。启用后，用户活动时会自动更新 `lastActiveAt` 字段。

```ts
dash({
  apiKey: process.env.BETTER_AUTH_API_KEY,
  activityTracking: {
    enabled: true,
    updateInterval: 300000,  // 更新间隔，单位毫秒（默认：5 分钟）
  },
}),
```

### 模式变更

启用活动跟踪时，插件会在您的用户模式中添加一个字段：

```ts
user: {
  fields: {
    lastActiveAt: {
      type: "date",
    },
  },
}
```

启用活动跟踪后，请务必运行数据库迁移。

## Managed Directory Sync

`managedDirectorySync` 选项是 SCIM 1.7 插件托管运行时流程在仪表盘侧的配套功能。当 `enabled` 为 `true` 时，仪表盘会安装托管目录同步状态所需的预留表和 API。`ssoPairing` 会启用目录关联用户身份与 SSO 提供商配对时所需的 SSO 钩子，而 `membershipProjection` 则允许系统将 SCIM 成员变更投影到组织成员记录中。

```ts
dash({
  apiKey: process.env.BETTER_AUTH_API_KEY,
  managedDirectorySync: {
    enabled: true,
  },
})
```

此功能专用于 1.7 托管目录同步流程。有关完整的托管目录同步模式和选项，请参阅 [仪表盘插件（`dash()`）中的托管目录同步部分](/docs/infrastructure/plugins/dash#managed-directory-sync)。有关完整的 SCIM 模型和迁移详情，请参阅 [SCIM 插件参考](/docs/plugins/scim/reference) 和 [1.7 升级指南](/docs/guides/1-7-upgrade-guide)。

## 客户端设置

```ts
import { createAuthClient } from "better-auth/client";
import { dashClient } from "@better-auth/infra/client";

export const authClient = createAuthClient({
  plugins: [dashClient()],
});
```

### 客户端配置

```ts
dashClient({
  resolveUserId: ({ userId, user, session }) => {
    return userId || user?.id || session?.user?.id;
  },
}),
```

## Dashboard 插件的功能

启用 `dash()` 后，Better Auth 基础设施仪表盘为您提供：

* **用户管理** — 查看、搜索、封禁和删除用户
* **会话监控** — 查看活跃会话并撤销它们
* **组织概览** — 管理组织和成员
* **分析功能** — 跟踪注册、登录和活跃用户随时间的变化
* **审计日志** — 查询事件历史记录（[了解更多](/docs/infrastructure/plugins/audit-logs)）

## 最佳实践

1. **始终设置 API 密钥** — 没有它，插件无法与基础设施 API 通信。

2. **合理使用活动跟踪** — 更新间隔会影响数据库写入频率。对于高流量应用，考虑使用更长的间隔。

3. **监控审计日志保留期限** — 不同套餐的保留周期不同，请检查您的套餐限制。

4. **保护您的端点** — 仪表盘端点需要认证。确保您的仪表盘用户拥有适当权限。
